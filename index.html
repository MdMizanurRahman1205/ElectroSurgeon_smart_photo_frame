Firmware installer

Ready to flash?

Connect your ESP32 board using a USB data cable, close any serial monitor, then press the install button. Choose the correct serial port when your browser asks.

Before you continue: Flashing can erase data already stored on the device. Use firmware only for compatible hardware. manifest.json.

ElectroSurgeon Smart Photo Frame ESP32 · USB SERIAL Your browser does not support Web Serial. Use desktop Chrome or Edge. Serial access is unavailable. Check browser permissions and use HTTPS.

Flash in three steps.

Follow these steps whenever you install a new release.

01

Connect the board

Plug your compatible ESP32 into your computer using a USB data cable.

02

Choose the port

Click Connect & Install Firmware and select the serial port for your board.

03

Install & reboot

Confirm the installation and keep the board connected until the process finishes.
